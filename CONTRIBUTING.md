# Contributing

Use Node.js 22 or newer. Run `npm ci`, `npm run check`, `npx playwright install chromium`, and `npm run test:browser`.

For a recovery bug, first add a failing behavior test. Model offer ownership, complete SDP signalling, registered event listeners, and room disposal accurately. A mocked successful rebuild is not evidence of a successful native WebRTC connection.

Use `npm run check:upstream` for optional read-only contract checks against public PokéBonk assets. Do not commit downloaded game code, game assets, accounts, room codes, cookies, tokens, ICE credentials, raw IP addresses, or private diagnostics.

For a different game, propose its adapter contract and a reproducible browser fixture first. Keep observation separate from actions that alter signalling. Explain which browser/transport versions were tested and which real-world scenarios remain unverified. See [the adapter notes](docs/ADAPTERS.md).

The project currently uses a Chinese in-game panel. Translations are welcome; do not change networking behavior in a translation patch.
